gh issue artifact edit

gh issue artifact edit {<issue> <artifact-number> | <artifact-url>} [flags]

Rename an issue artifact or replace its content. The type never changes, so a link's new content must be an http(s) URL or a .url Internet Shortcut file.

Name the artifact by its issue and number, or by its URL. <issue> is an issue number or URL.

With only --attach, the attachments are appended to the current content.

With --restore-version, an earlier version's name and content are saved as a new version. gh issue artifact view shows the edit history.

Options

--attach <file>
Attach an image or video file, in '<file>#<image alt text>' format
-b, --body <string>
New content; for a link, a URL
-F, --body-file <file>
Read new content from file (use "-" to read from standard input)
--name <string>
New name
--restore-version <number> (default 0)
Restore the version with this number from the edit history

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format
