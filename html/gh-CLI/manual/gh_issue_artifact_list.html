gh issue artifact list

gh issue artifact list {<issue-number> | <issue-url>} [flags]

List the artifacts on an issue, in number order. Every artifact is listed unless you set --limit.

Options

-q, --jq <expression>
Filter JSON output using a jq expression
--json <fields>
Output JSON with the specified fields
-L, --limit <int> (default 0)
Maximum number of artifacts to fetch
-t, --template <string>
Format JSON output using a Go template; see "gh help formatting"
--type <string>
Filter by type: {generic|plan|link|embedded_html}

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format

ALIASES

gh issue artifact ls

JSON Fields

body, bodyHtml, createdAt, creator, description, id, name, number, type, updatedAt, updatedByActor, url
