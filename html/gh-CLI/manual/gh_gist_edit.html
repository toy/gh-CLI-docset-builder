gh gist edit

Edit one of your gists

gh gist edit {<id> | <url>} [<filename>] [flags]

Options

-a, --add <string>
Add a new file to the gist
-d, --desc <string>
New description for the gist
-f, --filename <string>
Select a file to edit
-r, --remove <string>
Remove a file from the gist
