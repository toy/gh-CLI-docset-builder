gh issue artifact view

gh issue artifact view {<issue> <artifact-number> | <artifact-url>} [flags]

Display an issue artifact's name, type, authors, content, and edit history. A link shows its URL.

Name the artifact by its issue and number, or by its URL. <issue> is an issue number or URL.

By default, the current version is shown. Use --version to show an earlier version from the edit history.

With --web, open a document's page on GitHub, or a link's URL.

Options

-q, --jq <expression>
Filter JSON output using a jq expression
--json <fields>
Output JSON with the specified fields
-t, --template <string>
Format JSON output using a Go template; see "gh help formatting"
--version <number> (default 0)
Show the version with this number from the edit history
-w, --web
Open a document's page on GitHub, or a link's URL

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format

JSON Fields

body, bodyHtml, createdAt, creator, description, id, name, number, type, updatedAt, updatedByActor, url, versions
