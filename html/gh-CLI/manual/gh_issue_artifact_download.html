gh issue artifact download

gh issue artifact download {<issue> [<artifact-number>...] | <artifact-url>...} [flags]

Download issue artifacts to files. Without artifact numbers, every artifact on the issue is downloaded. Artifacts can also be named by their URLs, which must all be on one issue. <issue> is an issue number or URL.

Each file is named <number>-<name>. Markdown documents end in .md, HTML documents in .html, and links are saved as .url Internet Shortcut files. If a file already exists, that artifact fails unless you use --clobber to overwrite it or --skip-existing to skip it.

Use --dir to choose the directory to download files into, --output to choose the path for a single artifact, or --output - to print its content. Use --version with a single artifact to download an earlier version from its edit history.

Options

--clobber
Overwrite existing files of the same name
-D, --dir <directory> (default ".")
The directory to download files into
-O, --output <file>
The file to write a single artifact to (use "-" to write to standard output)
--skip-existing
Skip downloading when files of the same name exist
--version <number> (default 0)
Download the version with this number from the edit history

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format
