gh issue artifact create

gh issue artifact create {<issue-number> | <issue-url>} [<file>[#<name>] | <url>]... [flags]

Create one artifact for each file or URL. A text file becomes a document named after the file; add #<name> to choose a different name. A .html or .htm file becomes an HTML document. A URL, or a .url Internet Shortcut file, becomes a link; a URL is named after its host.

Artifact names can't contain some characters, such as parentheses. When a file's name has them, they're removed: plan (1).md is named plan 1.md.

Use --body to create a single document from text, or --body-file to create one artifact from a file (- reads standard input). --name sets its name.

Documents are saved as generic, and HTML documents as embedded_html. Use --type to set the type of every document instead, whatever the file extension. A plan currently behaves the same as a generic document.

Options

--attach <file>
Attach an image or video file, in '<file>#<image alt text>' format
-b, --body <string>
Content for a single document
-F, --body-file <file>
Read content for a single artifact from file (use "-" to read from standard input)
--name <string>
Name for a single artifact
--type <string>
Type for documents: {generic|plan|embedded_html}

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format

ALIASES
