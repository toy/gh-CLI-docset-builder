gh issue artifact

Working with issue artifacts in the GitHub CLI is in preview and subject to change without notice.

Issue artifacts are Markdown documents, HTML documents and links attached to an issue. They are not GitHub Actions artifacts; to download those, use gh run download.

Available commands

  • gh issue artifact create
  • gh issue artifact delete
  • gh issue artifact download
  • gh issue artifact edit
  • gh issue artifact list
  • gh issue artifact view

Options inherited from parent commands

-R, --repo <[HOST/]OWNER/REPO>
Select another repository using the [HOST/]OWNER/REPO format
