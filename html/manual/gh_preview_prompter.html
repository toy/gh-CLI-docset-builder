gh preview prompter

gh preview prompter [prompt type]

Execute a test program to preview the prompter. Without an argument, all prompts will be run.

Available prompt types:

  • select
  • multi-select
  • multi-select-with-search
  • input
  • password
  • confirm
  • auth-token
  • confirm-deletion
  • input-hostname
  • markdown-editor
